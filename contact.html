Contact

Talk to the person who builds it

AuraFlow is an independent project, not a support department. Email is the most reliable way to reach the developer — and there is no contact form because there is no backend to receive one.

Last updated: October 20, 2026

Email

thisissaddu3@gmail.com

For a faster reply, use a clear subject line: “Bug report”, “Privacy request”, or “Question about the organizer”. Please include the browser and version you used.

Website bugs and feature requests

The website is open source. You can open an issue on GitHub with the page URL, browser, steps to reproduce, and the exact error message. Screenshots of the interface are welcome; your personal files are not.

Privacy and data requests

AuraFlow does not receive your selected files or folder contents. If you have a question about the privacy policy, the hosting logs, or a future advertising disclosure, email thisissaddu3@gmail.com with “Privacy request” in the subject.

What not to send

Do not attach personal documents, photos, passwords, API keys, or any sensitive file. A description of the problem and a screenshot of the interface is almost always enough. AuraFlow cannot recover files that were moved or deleted outside the app; keep a backup and use the exported manifest if you need an audit trail.

Response expectations

Messages are answered on a best-effort basis. Bug reports with reproducible steps are prioritized. There is no guaranteed response time, paid support tier, or emergency service.
