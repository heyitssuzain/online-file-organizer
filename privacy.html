Privacy

What actually happens to your files

This page describes the real implementation, not aspirations. Each claim below maps to a specific technical fact about this site.

1. Files are never uploaded

AuraFlow Web has no backend that could receive files. The organizing logic is JavaScript that ships with the page itself and runs inside your browser tab. Categorization, previews, duplicate hashing and manifest generation all happen on your machine. There is no network request carrying any file data — you can verify this in your browser's dev tools (Network tab) while using the app.

2. Access is requested only when you act

The app asks for nothing until you click Select folder, Select files, or drop files onto the panel. When you organize into a real folder (Chromium browsers), your browser shows its own permission prompt and asks for read & write access to the exact folder you pick. AuraFlow only writes inside that folder, and only category folders it create for your confirmed plan.

3. No hidden analytics or telemetry

This site has no trackers, no analytics scripts, no cookies, no fingerprinting, and no third-party requests beyond this site's own assets. Your preference for light/dark theme is stored in your browser's localStorage — on your device, never transmitted.

4. What is (and isn't) stored

Stored locally, only in your own browser:

  • Your light/dark theme choice (localStorage)
  • Organized output you download (goes to your Downloads folder — you control it)

Not stored anywhere: the pages' in-memory list of your selected files, plan previews, duplicate hash results, executed run manifests. Close the tab and they are gone.

5. Duplicate detection only reads file contents

To find true duplicates, the app reads the bytes of same-size files and computes SHA-256 hashes — inside a Web Worker, in your browser, in streamed chunks. The hash is a fingerprint for comparison only; it is never sent anywhere and never written anywhere.

6. Security boundaries you should know about

Files you select are treated as data — never executed. Filenames shown in plans and manifests are HTML-escaped, and store only what you picked. The organized ZIP is built locally with a checksummed archive writer. No AI models, no external services, no "anonymous processing" — because there is nobody to process for.

7. Hosted pages (this website itself)

The site is served as static files from GitHub Pages. Standard web server access logs (IP address, dates, requested paths) are covered by GitHub's privacy policy and are not accessible to this project beyond what GitHub shares. AuraFlow does not add any of its own logging.

The one-line version

Your files stay on your device. Full stop.
