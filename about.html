About

Sort first. Ask permission. Undo your mistakes.

AuraFlow exists because folder chaos is universal and most solutions are either subscription software or silent auto-helpers that move things without asking.

The story so far

AuraFlow started as a Windows desktop app: a fast file organizer with a preview screen, one-click undo and a completely offline workflow. It's free and open source — the desktop project lives on GitHub, shipped as a lean ~26 MB executable that doesn't even need Python installed.

AuraFlow Web is its browser sibling: the same category engine and preview-first philosophy, reimplemented with browser technologies so it works on any OS — Windows, macOS, Linux, ChromeOS — without installing anything. The web edition's category lists, collision-renaming rules (-_1, -_2) and exclusion filters are direct ports of the desktop's proven logic, and this site's own test suite verifies that parity.

The philosophy

  • Preview before acting. A plan you can read beats an action you must hope for.
  • Never overwrite. Collisions get a safe rename, every time.
  • Undo matters. If a browser can't undo, say so — and export a manifest instead of an apology.
  • Local by default. Files don't travel to strangers' servers just to be sorted by extension.
  • Honest limits. A browser is not an OS app; this site says precisely where the line is.
