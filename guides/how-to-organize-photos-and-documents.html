How to organize photos and documents (they want different things)

Updated October 2026 · 5 min read

A photo collection and a document archive are different beasts wearing the same messy-folder costume. Apply one structure to both and one of them always ends up angry. The trick: photos are memory → organize by time; documents are utility → organize by purpose.

Photos: browse like a timeline

When was the last time you searched a photo by its filename? IMG_4471.jpg code names nothing. People retrieve photos by moment — "Trip month", "the birthday", "that weekend" — so a timeline beats any attempt at topical folders ("Beach", "Food" — someone always has to decide what a curry photo really is).

  • Sort by month (2025-04/). A date-organized pass groups everything by last-modified month. Phone and camera files land in the month they were taken; rescans and edits drift forward by a month or two — acceptable friction.
  • Keep the originals rule. If your sort ends up with Copy of IMG_4471.jpg-type duplicates, that's editing-induced duplication (exported variants, app copies). Run duplicate detection after the first pass — content hashing finds the true copies, filenames none the wiser.
  • Screenshots are a special breed. No dates you care about, endless iterations. A dedicated Images/Screenshots/ pass (extension rule for .png plus a look at names) saves the timeline from being wallpaper-only.

Documents: browse like a task

Documents are not remembered by month; they're remembered by job: the contract, the application, the shipment. Time-based folders hide things here.

  • Sort by type first — Documents/ splits text and spreadsheets from PDF folders. Fine as the landing structure.
  • Then name with intent. Files like resume_v3_2026.pdf say more than folder structure ever will. Make the habit stick: [domain]_[document]_[year]. Renaming takes two seconds and pays back every search.
  • Keep a yearly sweep for "flotsam." Lone PDFs you'd open to identify can stay in the top-level Documents/. A quarterly "do I still need each of these?" pass beats trying to taxonomize everything at once.
One pass, two structures — is that possible? Run the organizer by date first (everything into months), then run a second pass by type on each month's Images and Documents children if you want finer structure. Two planned passes beat one unreviewable mega-pass.

The folder-exile list

Some things are classified but never feel organized. A shared quarantine folder for odd cases helps: scanned receipts you'll need once, downloads for a single print, rare format files (.heic, proprietary design files). Name it something you'll recognize, e.g. Others. AuraFlow sends unknown extensions there too — never discarded, just weighted.

Fast win: the "photo dump from a phone" pattern

  1. Plug the phone (or drag its camera folder onto the Organizer over to a local folder first).
  2. Run by date → month folders appear.
  3. Confirm, download the manifest for records, unplug.
  4. Lose the guilt about the 4,000 photos in the root directory — they're in a timeline now.

Start with a date run on the messiest camera dump you own.
