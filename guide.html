Help & guide

Using AuraFlow Web, step by step

Five minutes from messy to tidy. If anything goes wrong, the troubleshooting section at the bottom covers every known failure mode.

1. Choose what to organize

On the Organizer page you have three ways to select files:

  • Select folder — opens your browser's folder picker. In Chrome/Edge, this grants read access and enables real sorting later. Elsewhere it uses the classic picker.
  • Select files — pick individual files with Ctrl/Cmd-click multi-select. Ideal for small jobs.
  • Drag & drop — drop files anywhere on the drop panel; in Chromium you can drop whole folders too.

The selection is capped at 5,000 files. If you need to organize more, run it in two passes — large batches rarely improve the result, they just slow the page.

2. Review the plan

Every file appears with its category, size, and proposed destination. Switch the rule at the top of the plan:

  • By type — Images/photo.jpg. The classic.
  • By extension — Videos/mp4/clip.mp4. Great for huge mixed dumps.
  • By date — 2025-04/Images/photo.jpg. Groups by last-modified month.

Watch for three signals: a renamed badge (the plan found a name conflict and renamed the new copy — nothing overwrites), the skipped notes (temp/system files stay in place), and the file count badges up top.

3. Duplicates (optional)

Click Find duplicates. Files are compared by size first, then by streaming SHA-256 hash — so a genuine duplicate is identical content, found even under different names. AuraFlow flags groups; it never deletes automatically. Move or delete with your own file manager, then re-run the organizer.

4. Execute — two honest modes

Sort into a real folder (Chrome, Edge, Opera, Brave): after Organize, your browser asks again for the destination folder and read & write permission. Confirm once, watch the progress, and the files are moved into category folders. Undo this run restores everything for as long as the tab stays open.

Organized ZIP download (Firefox, Safari, mobile browsers): the browser cannot write folders, so AuraFlow produces a single ZIP mirroring the plan's structure — drop its contents into any folder on your device. You download it; you decide where it lives.

Either way, download the manifest (JSON/CSV/TXT) at the end. It lists every move — an audit record and a recipe to undo manually anytime.

5. Troubleshooting — every known error, decoded

What you seeWhat it means & the fix
“Selection capped at the first 5,000 files”You picked a very large tree. Organize in batches — the limit keeps the page fast.
Move error, “permission denied”The file may be open in another program, or the folder lost write permission. Close the app holding it (media players love to do this), then run again. Everything else in the run still organized.
A file fails with “already exists”Something was created between the plan and the run. The manifest shows exactly which file; rerun the organizer — the plan will propose a fresh non-conflicting name.
“…over 512 MB couldn't be hashed”The file skipped duplicate-hashing (browser cap). It still organizes normally.
ZIP exceeds 2 GBThe selection is too large for one archive in your browser's memory limits. Organize fewer files per run, or switch to Chrome/Edge for direct folder sorting.
Undo button missingUndo needs the same tab session that did the organizing (Chromium). Use the manifest files to reverse manually.
Nothing organized / empty planAll files were skipped (temp/system) or you selected a folder whose contents are all in subfolders beyond the 3-level scan depth.

6. Supported browsers, plainly

  • Chrome 86+, Edge 86+, Opera, Brave — full experience: folder reading, direct sorting, undo.
  • Firefox, Safari 14+ — file reading, planning, duplicates, manifest exports and the organized ZIP. No direct folder writes (browser limitation, not a paywall!).
  • Mobile browsers — selection (files or photos), planning and ZIP download work; folder writing does not.
