Merged PDF

Built locally

Document outlines, forms, embedded files and some annotations may not survive merging. The page content itself is not rasterized.

Documents stay on your device

  • PDFs are read with the File API in this tab.
  • Page counts and page copying run in a local Web Worker with pdf-lib.
  • No uploads, accounts, tracking or document history.
  • Closing the tab discards the merge queue.
  • The downloaded file is yours to keep or delete.

What is preserved

  • Page order, page sizes and orientation.
  • Selectable text, fonts and vector artwork.
  • Original page content rather than a screenshot.

Not guaranteed by the local library: PDF outlines/bookmarks, AcroForm fields, embedded files and rare annotation types.

Encrypted PDFs

A password-protected PDF is rejected with a clear message. Unlock it in your PDF reader, export an unprotected copy, then add it here. AuraFlow does not ask for or transmit passwords.
