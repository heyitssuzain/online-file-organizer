Privacy by default

  • Files are read with the browser's own file API.
  • Conversion happens in memory in this tab.
  • No uploads, accounts, analytics or file history.
  • Only your theme choice is stored locally.
  • Closing or reloading the page drops the queue.
  • Downloads are normal files you control.

What converts here

Images: PNG, JPG/JPEG, WebP, BMP, GIF, SVG, AVIF and browser-decodable ICO.

PNGJPGWebPBMP

Documents: TXT, Markdown and HTML to PDF, HTML, Markdown or plain text where meaningful.

PDFHTMLMDTXT

Data: CSV, TSV and JSON to CSV, JSON or a real XLSX workbook.

CSVJSONXLSX

Audio/video conversion is not advertised: a reliable, fully local engine is not bundled. PDFs belong in Image → PDF or PDF Merger.

Honest limits

  • GIF becomes a still image (first frame).
  • Large images can hit browser canvas memory limits; downscale if needed.
  • Text is read as UTF-8 or UTF-16. Legacy encodings may need re-saving.
  • HTML → PDF extracts readable text; it does not reproduce CSS layout or images.
  • Text PDFs use a bundled Latin/Greek/Cyrillic font. CJK and emoji are rejected with the missing characters instead of being silently blanked.
  • XLSX export is one-way; this tool does not open spreadsheets.
  • Keep the tab open while converting.
