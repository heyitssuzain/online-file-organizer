How it works

Three steps. Zero surprises.

1. Choose your files

Pick a folder or drag files in. Files are read locally by your browser — nothing is uploaded anywhere.

2. Review the plan

Every file is shown with its category and destination. Name conflicts are detected before they happen — nothing is overwritten.

3. Confirm & undo anytime

Sort into a real folder (where your browser allows it) or download an organized ZIP. Every run includes a manifest you can keep — or one-click undo.

Batch processing

Thousands of files categorized, sized and conflict-checked in one pass — in a background thread where your browser supports it.

Duplicate detection

Real content hashing (SHA-256), not name matching. Same name ≠ same file; identical content, even with different names, is found.

Privacy & safety

Your files stay on your device

AuraFlow Web requests file access only when you choose files, and only in the tab you're using. There is no backend that could ever receive a file, because the organizing logic ships with the page itself.

  • Nothing is uploaded — all categorization, previews and exports are local
  • No accounts, no tracking, no hidden analytics or telemetry
  • Folder writing happens only after an explicit "read & write" permission grant
  • The desktop app keeps the same promise — it even shows a preview and one-click undo

FAQ

Fair questions, straight answers

Are my files uploaded anywhere?

No. There is no server involved in organizing — everything runs as JavaScript in your own browser tab. You can even use it offline once the page has loaded.

Can it organize into a real folder on my disk?

Yes, in Chromium browsers (Chrome, Edge, Opera, Brave) via the File System Access API — you explicitly grant "read & write" for the folder you pick. Firefox and Safari don't support folder writes yet, so AuraFlow offers an organized ZIP download there instead. Details

Will it overwrite my existing files?

Never. Collisions are detected before the run against both the plan itself and the files already present in the destination folder; extra copies get a safe _1 suffix, identical to the desktop app's behaviour.

Is it really free?

Yes — the web edition and the Windows desktop app are both free and open source (MIT). No accounts, no subscriptions, no locked features.

How does duplicate detection work?

Files are grouped by size, then only same-size candidates are hashed (SHA-256) in a background thread, streamed in chunks so memory stays flat. Identical content is flagged even when filenames differ.

What about the Windows app?

AuraFlow (desktop) is a separate, full-featured Windows executable with drag & drop, recursive scans and one-click undo. The web edition can't recursively write subfolders like a native app — here's an honest comparison.
